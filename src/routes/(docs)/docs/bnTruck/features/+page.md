# Systems & Features

**Logistics Tablet**: job assignments across cargo types (General, Hazardous, Vehicles, Maritime). Company owners set up hierarchies, driver commissions, and financial dashboards. Multiple drivers can run convoy operations on large contracts together.

**Mobile Fiscal Terminal (MFT)**: enforcement device for police and inspectors. Every time a truck passes a weigh station, real weight is compared against the invoice's declared weight; discrepancies alert active MFT terminals automatically.

**Risk & reward**: under-declaring cargo weight cuts taxes but raises detection risk at weigh stations. Advanced trailers add hidden compartments for contraband, with detection difficulty depending on cargo type.

**K-9 detection**: probability-based search, not a guaranteed hit. Success depends on distance, cargo type, and whether items are hidden in a false bottom.

**Persistent economy**: MySQL-backed financial records, company progression tiers, and driver performance tracking. Bridges QBCore, ESX, and Qbox automatically.
