# Gameplay Guide

## Starting out

Two paths: work as a **Freelance Worker (Solo)** with no investment, or build a **Logistics Company** by visiting the company headquarters and registering a name (and optional logo).

## The Logistics Tablet

Command center for the job, opened via the `truck_device` item or `/trucktablet`. Has a dashboard (finances), an assignments tab (browsing cargo contracts), and fleet management (spawning vehicles).

## The transport cycle

1. Load cargo at the logistics hub, manually or automatically.
2. Issue an invoice with `/nota`, declaring the weight honestly or fraudulently.
3. Drive to the destination, potentially passing weigh stations.
4. Unload and return the vehicle to collect payment.

## Risk vs. reward

Declaring the real weight is the safest option. Under-declaring reduces taxes but risks detection at a weigh station, which compares real weight against the declared invoice and can trigger alerts to active MFT terminals.

## Law enforcement

Inspectors use the MFT (`/mft`) to check trucks, deploy K-9 units to search false-bottom compartments, issue fines, and review appeals from companies.

## Advanced features

Premium trailers have false-bottom compartments for concealing illegal cargo. Companies can buy transport permits to unlock restricted cargo categories (e.g. nuclear materials, vehicles).
