# Commands

| Command | Purpose |
|---------|---------|
| `/trucktablet` | Opens the Logistics Tablet for the player |
| `/nota` | Opens the invoice UI to declare cargo weight |
| `/mft` | Opens the Mobile Fiscal Terminal (inspectors only) |
| `/contratar [player_id]` | Hires a player into your company (owners only) |
