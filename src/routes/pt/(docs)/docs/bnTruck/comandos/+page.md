# Comandos

| Comando | Função |
|---------|--------|
| `/trucktablet` | Abre o Tablet do Caminhoneiro |
| `/nota` | Abre a interface pra declarar o peso da carga |
| `/mft` | Abre o Terminal Fiscal Móvel (só fiscais) |
| `/contratar [player_id]` | Contrata um jogador pra empresa (só donos) |
